# FrogAI

FrogAI makes Continue agents behave like senior software architects during project analysis.

## Installation

```sh
./install-continue-project-analysis.sh /path/to/your/project
```

## Usage

Open your project in Continue Agent mode and ask:

```
Analyze this project.
```

The agent will inspect the repository, separate observations from assumptions, provide evidence for conclusions, and recommend next engineering steps.
